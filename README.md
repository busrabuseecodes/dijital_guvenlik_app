# Dijital Güvenlik Uygulaması 🛡️

**Dijital dünyada daha bilinçli ve güvenli adımlar atmak için geliştirilen mobil güvenlik uygulaması.**

Dijital Güvenlik Uygulaması; kimlik hırsızlığı, oltalama (phishing) saldırıları ve kişisel veri güvenliği gibi konularda kullanıcıların farkındalığını artırmayı amaçlayan bir mobil uygulama projesidir.

Projenin temel amacı, kullanıcıların dijital tehditleri tanımasını, güvenli internet alışkanlıkları kazanmasını ve kişisel verilerini koruma konusunda bilinçlenmesini sağlamaktır.

---

## ✨ Özellikler

- **Şifre Oluşturucu:** Güçlü ve rastgele şifreler oluşturulmasına yardımcı olur.
- **Şifre Gücü Analizörü:** Şifrelerin güvenlik seviyesini değerlendirmeyi hedefler.
- **Kimlik Avı Simülatörü:** Oltalama saldırılarını tanımaya yönelik örnek senaryolar sunmayı amaçlar.
- **Siber Güvenlik Haberleri:** Güncel siber güvenlik gelişmelerinin takip edilmesini hedefler.
- **Dijital Güvenlik Rehberi:** Güvenli internet, sosyal medya ve kişisel veri kullanımı hakkında bilgiler sunmayı amaçlar.

## 💡 Projenin Amacı

Bu projenin amacı, kullanıcıların dijital dünyadaki tehditlere karşı daha bilinçli hareket etmelerini sağlamaktır.

- Dijital tehditleri tanıma
- Güçlü şifre oluşturma alışkanlığı kazanma
- Oltalama saldırılarını ayırt etme
- Kişisel verileri koruma
- Güvenli internet alışkanlıkları geliştirme

## 💻 Kullanılan Teknolojiler

- **Flutter:** Mobil uygulama geliştirme framework'ü.
- **Dart:** Programlama dili.
